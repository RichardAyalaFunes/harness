# Founding Engineer (Kestrel Labs)

## About us
Kestrel Labs is two founders building scheduling software for independent physiotherapy clinics. We have 12 pilot clinics and no engineers yet.

## What you'll do
- Build our product from the prototype into something clinics rely on.
- Own the whole stack, from database to the booking screens.
- Set up how we build: deployments, testing, code review.
- Help hire the next engineers.

## What we're looking for
- You have built and shipped a full-stack web product end to end.
- TypeScript and a relational database.
- Comfortable talking to customers.

## Practical
Salary €60–70k plus equity. Remote in Portugal or Spain. Start as soon as possible.
